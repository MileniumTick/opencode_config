# Templates

Use these bundles to quickly bootstrap project-specific AI workflows in OpenCode.

- **backend-project/** — API/service-focused setup for implementation-heavy backend work.
- **finance-project/** — Market/trading analysis setup for screening, signals, and portfolio workflows.
- **research-project/** — Structured investigation setup for discovery, comparisons, and due diligence.
- **content-project/** — Documentation and content production setup for technical and product communication.
